# 📱 সালাম কল (Salam Call) - cPanel Hosting & PHP PWA Package

সালাম কল (Salam Call) হলো একটি সম্পূর্ণ পিএইচপি (PHP) ও প্রোগ্রেসিভ ওয়েব অ্যাপ (PWA) ভিত্তিক আইপি টেলিফোনি কলিং অ্যাপ্লিকেশন।

---

## 📁 ফোল্ডার এবং ফাইল স্ট্রাকচার (cPanel Package)

```text
salam_call_php/
│
├── index.php                 # মূল ড্যাশবোর্ড ও মোবাইল ইন্টারফেস
├── login.php                 # লগইন পেজ (JSON ভিত্তিক দ্রুত ভেরিফিকেশন)
├── register.php              # রেজিস্ট্রেশন পেজ (NID ছবি প্রিভিউ ও 09612 আইপি নম্বর নির্বাচন)
├── verify-otp.php            # জিমেইল ওটিপি ভেরিফিকেশন (FormSubmit AJAX ইন্টিগ্রেটেড)
├── dialer.php                # DTMF ডায়াল প্যাড ও লাইভ কলিং কী-প্যাড
├── call-active.php           # এক্টিভ কল স্ক্রিন (টেলিফোনি রিংটোন, টাইমার ও অডিও)
├── contacts.php              # ফোনবুক ও আইপি কন্টাক্টস তালিকা
├── history.php               # ইনকামিং ও আউটগোয়িং কল হিস্ট্রি লগ
├── recharge.php              # বিকাশ/নগদ/রকেট ব্যালেন্স রিচার্জ পোর্টাল
├── profile.php               # ইউজার প্রোফাইল ও BTRC KYC স্ট্যাটাস
├── admin.php                 # অ্যাডমিন কন্ট্রোল প্যানেল (অনুমোদন, ব্যালেন্স প্রদান ও NID ভিউ)
├── logout.php                # নিরাপদ লগআউট স্ক্রিপ্ট
│
├── manifest.json             # Web App Manifest (ব্রাউজার থেকে ইন্সটলযোগ্য করার কনফিগারেশন)
├── sw.js                     # Service Worker (অফলাইন ক্যাশিং ও পুশ সাপোর্ট)
├── .htaccess                 # Apache সিকিউরিটি ও ক্যাশিং কনফিগারেশন
│
├── includes/
│   ├── config.php            # কোর কনফিগারেশন ও থ্রেড-সেফ JSON রিড/রাইট ইঞ্জিন
│   ├── header.php            # মোবাইল অ্যাপ হেডার ও PWA ব্যানার
│   └── footer.php            # বটম নেভিগেশন বার
│
├── data/
│   ├── .htaccess             # সরাসরি ব্রাউজার ডাউনলোড থেকে JSON ডাটা প্রটেকশন
│   ├── user.json             # সকল নিবন্ধিত ইউজারের স্থায়ী ডাটাবেস
│   ├── calls.json            # কল হিস্ট্রি ডাটাবেস
│   ├── contacts.json         # সংরক্ষিত কন্টাক্ট ডাটাবেস
│   └── recharges.json        # রিচার্জের তথ্যাদি
│
├── uploads/                  # আপলোডকৃত NID কার্ডের আসল ছবির ফোল্ডার
│
└── assets/
    ├── css/style.css         # আধুনিক ডার্ক ও এমারেল্ড থিম মোবাইল অ্যাপ UI স্টাইলিং
    ├── js/app.js             # PWA ইন্সটলার ও FormSubmit AJAX ওটিপি ইঞ্জিন
    ├── js/dialer.js          # Web Audio API DTMF অডিও সাউন্ড ও ডায়ালিং লজিক
    └── icons/                # PWA অ্যাপ আইকন (192x192 & 512x512)
```

## 🚀 cPanel / Web Hosting এ আপলোড করার নিয়ম:

1. আপনার হোস্টিং এর **cPanel**-এ লগইন করুন।
2. **File Manager** ওপেন করে `public_html` ফোল্ডারে প্রবেশ করুন (বা আপনার সাব-ডোমেইনের ফোল্ডারে)।
3. `salam_call_php` ফোল্ডারের ভেতরের সমস্ত ফাইল ও ফোল্ডার আপলোড করে Extract করুন।
4. `data` এবং `uploads` ফোল্ডারের পারমিশন **755** অথবা **777** রয়েছে কিনা নিশ্চিত করুন।
5. ব্যস! আপনার ডোমেইনে ব্রাউজ করলেই পুরো সালাম কল সিস্টেম সরাসরি চালু হয়ে যাবে। কোনো MySQL ডাটাবেজ বানানোর প্রয়োজন নেই!

## 📲 ব্রাউজার থেকে অ্যাপ হিসেবে ইনস্টল করার নিয়ম (PWA):

1. অ্যান্ড্রয়েড ফোনে **Google Chrome** অথবা আইফোনে **Safari** দিয়ে আপনার সাইটে প্রবেশ করুন।
2. স্ক্রিনের উপরে স্বয়ংক্রিয়ভাবে **"সালাম কল অ্যাপ ইনস্টল করুন"** ব্যানার দেখতে পাবেন অথবা ব্রাউজার মেন্যু থেকে **"Install app"** বা **"Add to Home screen"**-এ চাপ দিন।
3. মোবাইল স্ক্রিনে সাধারণ অ্যাপের মতো আইকন চলে আসবে এবং ফুলস্ক্রিনে চলবে।
