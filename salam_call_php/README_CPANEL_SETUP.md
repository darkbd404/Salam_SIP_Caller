# 📱 সালাম কল (Salam Call) - PHP & PWA Hosting Guide for cPanel

এই প্রজেক্টটি একটি কমপ্লিট **PHP + PWA (Progressive Web App)** টেলিফোনি অ্যাপ্লিকেশন। এটি কোনো জটিল ডাটাবেস (MySQL) সেটআপ ছাড়াই সরাসরি যেকোনো **cPanel / Apache / Nginx / Shared Web Hosting** প্যানেলে চালানো যাবে।

---

## 📁 ফোল্ডার এবং ফাইল স্ট্রাকচার:

```text
salam_call_php/
│
├── index.php                 # মূল ড্যাশবোর্ড ও হোম স্ক্রিন
├── login.php                 # লগইন পেজ (JSON ভিত্তিক অথেনটিকেশন)
├── register.php              # রেজিস্ট্রেশন পেজ (NID ছবি প্রিভিউ ও কাস্টম IP নম্বর নির্বাচন)
├── verify-otp.php            # জিমেইল ওটিপি ভেরিফিকেশন (FormSubmit AJAX ইন্টিগ্রেটেড)
├── dialer.php                # DTMF ডায়াল প্যাড ও লাইভ কলিং কীপ্যাড
├── call-active.php           # এক্টিভ কল স্ক্রিন (WebRTC অডিও টোন, রিং ও টাইমার)
├── contacts.php              # ফোনবুক ও আইপি কন্টাক্টস তালিকা
├── history.php               # কল লগ ও হিস্ট্রি রেকর্ড
├── recharge.php              # বিকাশ/নগদ/রকেট ব্যালেন্স রিচার্জ পোর্টাল
├── profile.php               # ইউজার প্রোফাইল ও BTRC KYC পরিচিতি
├── admin.php                 # অ্যাডমিন কন্ট্রোল প্যানেল (ইউজার অনুমোদন, ব্লক/আনব্লক, ব্যালেন্স যোগ)
├── logout.php                # লগআউট স্ক্রিপ্ট
│
├── manifest.json             # PWA ম্যানিফেস্ট (ব্রাউজার থেকে ইন্সটলযোগ্য)
├── sw.js                     # PWA সার্ভিস ওয়ার্কার ও অফলাইন ক্যাশ
├── .htaccess                 # অ্যাপাচি কনফিগারেশন
│
├── includes/
│   ├── config.php            # কোর কনফিগারেশন ও থ্রেড-সেফ JSON রিড/রাইট ইঞ্জিন
│   ├── header.php            # মোবাইল অ্যাপ হেডার ও PWA ব্যানার
│   └── footer.php            # বটম নেভিগেশন বার
│
├── data/
│   ├── user.json             # সকল নিবন্ধিত ইউজারের সম্পূর্ণ ডাটাবেস
│   ├── calls.json            # কল হিস্ট্রি ডাটাবেস
│   ├── contacts.json         # সংরক্ষিত কন্টাক্ট ডাটাবেস
│   └── recharges.json        # রিচার্জের তথ্যাদি
│
├── uploads/                  # আপলোড করা NID কার্ডের সামনের ও পিছনের ছবি
│
└── assets/
    ├── css/style.css         # আধুনিক ডার্ক মোড মোবাইল অ্যাপ UI স্টাইলিং
    ├── js/app.js             # PWA ইন্সটলার ও FormSubmit AJAX স্ক্রিপ্ট
    ├── js/dialer.js          # Web Audio API DTMF টোন ও ডায়ালিং লজিক
    └── icons/                # PWA অ্যাপ আইকন (192px & 512px)
```

## 🚀 cPanel-এ হোস্ট করার সহজ নিয়ম:

1. **cPanel এ লগইন করুন** এবং **File Manager** ওপেন করুন।
2. `public_html` ফোল্ডারে প্রবেশ করুন (অথবা সাব-ডোমেইনের ফোল্ডারে)।
3. `salam_call_php` ফোল্ডারের ভিতরের সব ফাইল ও ফোল্ডার জিপ (ZIP) করে আপলোড করুন এবং Extract করুন।
4. `data` এবং `uploads` ফোল্ডার দুটির Permission **755** অথবা **777** রয়েছে কিনা নিশ্চিত করুন (যাতে PHP সহজে `user.json` এবং ছবি সেভ করতে পারে)।
5. ব্যাস! আপনার ডোমেইন বা লিংকে ব্রাউজ করলেই পুরো সালাম কল অ্যাপ চালু হয়ে যাবে।

---

## 📲 ব্রাউজার থেকে অ্যাপ হিসেবে ইনস্টল করার নিয়ম (PWA):

1. যেকোনো অ্যান্ড্রয়েড ফোনে **Google Chrome** বা আইফোনে **Safari** দিয়ে আপনার সাইট ওপেন করুন।
2. স্ক্রিনের উপরে স্বয়ংক্রিয়ভাবে **"সালাম কল অ্যাপ ইনস্টল করুন"** ব্যানার দেখতে পাবেন অথবা ব্রাউজারের থ্রি-ডট (⋮) মেন্যু থেকে **"Install app"** বা **"Add to Home screen"**-এ চাপ দিন।
3. মোবাইল স্ক্রিনে আসল অ্যান্ড্রয়েড অ্যাপের মতো ইনস্টল হয়ে যাবে এবং কোনো অ্যাপ স্টোর ছাড়াই অফলাইন ও ফুলস্ক্রিনে চলবে!

## 🔑 ডিফল্ট অ্যাডমিন একাউন্ট:

- প্রথম যে ইউজার রেজিস্ট্রেশন করবেন তিনি স্বয়ংক্রিয়ভাবে **ADMIN** একসেস পাবেন।
- অ্যাডমিন প্যানেল সরাসরি দেখতে: `yourdomain.com/admin.php`
- অ্যাডমিন প্যানেল থেকে যেকোনো ইউজারের কল সুবিধা চালু/বন্ধ, ব্যালেন্স রিচার্জ ও NID কার্ড দেখা যাবে।
